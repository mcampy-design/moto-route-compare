Add both routes to compare them.Each one can come from a GPX file or a Google Maps link.
GPX files are read in your browser and never uploaded. Google links are routed through a private service that holds the API key, so no key is ever exposed on this page. Tree cover: the route's points, minus the first and last half mile, are sent to a public USDA Forest Service map service. Traffic: the page downloads public USDOT (FHWA) traffic tiles for the areas the route crosses and matches them in your browser, so no route points are sent for traffic. Anything that can't be looked up is estimated from road shape.
